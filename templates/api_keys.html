How to get a free Gemini API key

  1. Open Google AI Studio

    Go to aistudio.google.com/apikey and sign in with your Google account.

  2. Create the key

    Click “Create API key”. If asked, choose or create a Google Cloud project (the default one is fine).

  3. Copy it

    Copy the key that appears. It starts with AIza and is about 39 characters long.

  4. Paste it here

    Paste it into the Gemini API key box, give it a name, and click Verify & save key.

  5. Start practising

    That's it: interviews, Talk, speaking practice and your question sets now use your key.

💡 Why add more than one key? The free tier has daily request limits. If your default key runs out, the app automatically switches to your next key, so you can keep practising.
🔒 Keep it private. Never share your key or post it online. If it leaks, delete it in AI Studio, create a new one, and use Edit → Replace the key here.
ℹ️ Usage on the free tier is limited per day and per minute. Each interview uses about 3–5 requests; every Talk or speaking-practice reply uses 1. See your usage at aistudio.google.com/usage.
